# Support

InfraLens **0.1.x** is a **public preview**.

## What to expect

- The project is open source and volunteer-maintained.
- Features marked experimental may change without a long deprecation cycle.
- Documentation and UX will improve quickly; sharp edges are expected.
- There is **no SLA**, no guaranteed response time, and no paid support channel
  implied by this repository.

## How to get help

1. Read [docs/overview.md](docs/overview.md) and [docs/product/limitations.md](docs/product/limitations.md).
2. Try the local demo: `npm install && npm run demo`.
3. Search existing [GitHub Issues](https://github.com/markndg/InfraLens/issues).
4. Open a new issue with the bug or feature template.

Please include InfraLens version (`0.1.x`), Node version, the command you ran, and a minimal
fixture or redacted bundle when reporting defects.

## What not to expect

- Private consulting via Issues
- Guaranteed fixes for every preview limitation
- Production support commitments for multi-tenant hosted deployments

Security issues: use GitHub private vulnerability reporting — see [SECURITY.md](SECURITY.md).
Community behaviour: see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
