# InfraLens 0.1.0 — Architecture Governance Public Preview

**Release date:** 2026-08-06  
**Licence:** Apache-2.0 (fully open source; no commercial edition)  
**Repository:** https://github.com/markndg/InfraLens

## Headline

InfraLens proves whether the architecture you are running still matches the architecture you intended — with evidence behind every conclusion, and approval that invalidates when the architecture changes.

Analysis is **deterministic**. Reconstruction, projections, reviews, and recommendations do not require an LLM.

## What’s in the preview

- **Evidence graph** with truth states, confidence, and source-backed evidence on resources, edges, and findings
- **Architecture projections** (capability, application, physical, data, ownership, security, risk, governance/decision, and supporting views) with explicit [projection contracts](../architecture/projection-contracts.md)
- **Governance**: intents, ADRs, assumptions, contracts/obligations, decision graph, staged review, sign-off bound to evidence state
- **Deterministic intelligence**: narrative, blast radius, counterfactual simulation, timeline, DNA
- **Local scanner CLI**: `scan`, `inspect`, `compare`, `report`, `capabilities`
- **Workbench UI** and optional local API bridge
- **One-command demo**: `npm run demo` (Node ≥ 20) → http://localhost:5173
- **Verification gate**: `npm run verify`
- **Reference estates**: Retail SaaS, Serverless AWS, Kubernetes microservices, Legacy hybrid
- **Hosted-demo build**: `npm run build:demo` → `apps/web/dist-demo` (no credentials; banner on)
- **Hero visual**: [docs/assets/infralens-hero.svg](../assets/infralens-hero.svg)
- **30s storyboard**: [docs/assets/demo/STORYBOARD.md](../assets/demo/STORYBOARD.md) (`npm run demo:record`)
- Edition gates removed — capability registry describes **runtime readiness** only ([migration note](../product/migration-from-editions.md))

## Known limitations

Honest preview boundaries (not fine print):

- Terraform without plan/state uses bounded HCL; full module/expression resolution is incomplete
- Helm/Kustomize supported as **rendered** manifests only
- Live AWS / cluster connectors need credentials; disabled by default; prefer snapshots
- Portfolio / organisational graph features are early; persistence is local / in-memory oriented
- Large-graph performance and UX polish have sharp edges
- CI enforcement and some connectors are experimental

Full list: [product/limitations.md](../product/limitations.md) · [capability-matrix.md](../product/capability-matrix.md)

## Upgrade / migration notes

If you used pre-0.1 trees with OSS/commercial edition flags, remove `INFRALENS_EDITION` gating assumptions. See [migration-from-editions.md](../product/migration-from-editions.md). Existing scan bundles should continue to open; obsolete edition fields are ignored.
