# Evidence model

Every resource, edge and finding retains evidence.

`EvidenceRecord` fields: adapter, sourceType, sourceUri, location, contentHash, repositoryRevision, observedAt, extractedValue, redacted, confidence, rationale, truthState.

Truth states: declared, evaluated, rendered, planned, observed, inferred, assumed, historical.

Confidence includes band, reasons, missing evidence, conflicts, inference method, and what would increase confidence.

Select any node to answer: **Why does InfraLens believe this exists?**
