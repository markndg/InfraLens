# Product overview

InfraLens is an **Architecture Governance Platform** for mixed application estates.

The canonical model remains a typed **evidence knowledge graph**, now including decisions, intents, assumptions, contracts, obligations and ADRs. Reviews remain a first-class activity inside governance. The product answers: *are we still building the architecture we intended?*

## Who it is for

- Enterprise / platform / security / data / operations architects conducting board-ready reviews
- Platform engineers validating production readiness
- Auditors needing evidence-bound approval history

## Non-negotiable principles

1. Evidence before inference
2. Review outcomes reproducible from graph traversal (no LLM)
3. Unknowns are first-class
4. Multiple remediation options with explicit trade-offs
5. OSS/commercial boundaries enforced by the capability registry
6. Local-first and safe by default
