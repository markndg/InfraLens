# Product overview

InfraLens is an **Architecture Governance** platform for mixed application estates.

The canonical model is a typed **evidence knowledge graph**, including decisions, intents,
assumptions, contracts, obligations, and ADRs. Reviews are a first-class activity inside governance.
The product answers: *are we still building the architecture we intended?*

## Who it is for

- Enterprise / platform / security / data / operations architects conducting evidence-backed reviews
- Platform engineers validating production readiness
- Auditors needing evidence-bound approval history

## Non-negotiable principles

1. Evidence before inference
2. Review outcomes reproducible from graph traversal (no LLM required for core analysis)
3. Unknowns are first-class
4. Multiple remediation options with explicit trade-offs
5. One fully open-source product — capability registry describes runtime readiness, not licensing
6. Local-first and safe by default
